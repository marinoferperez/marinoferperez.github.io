Forecasting electricity demand

From time-series baselines to probabilistic forecasts and a reproducible prediction service.

2026Planned project

Overview

This project is a proposal, not a completed system. The aim is to forecast Spanish electricity demand while making uncertainty visible and the workflow reproducible.

Problem

A single demand estimate hides the range of plausible outcomes. The proposed study asks how well a forecast can describe both expected demand and uncertainty under changing conditions.

Research / approach

Start with seasonal naïve baselines, then compare statistical and machine learning approaches. More complex models should earn their place through measurable improvements under the same evaluation protocol.

Dataset

Historical Spanish electricity demand and meteorological observations are candidate inputs. Sources, licensing, temporal coverage, and availability at prediction time still need to be verified.

Methodology

Use chronological splits and rolling-origin evaluation. Fit all transformations within each training window to prevent leakage. Assess point forecasts separately from prediction-interval coverage and width.

Experiments

Planned comparisons include calendar-only features versus weather-enriched inputs, different forecast horizons, and performance across seasons. Experiment tracking would record configurations, metrics, and artifacts.

Results

Experiments have not started. Results and error analysis will be published after the evaluation is complete.

Engineering / production

The intended deliverable is a reproducible training pipeline and a small prediction API, with a containerised environment, automated checks, and documented deployment. These components are planned rather than implemented.

Limitations

Weather forecasts available at prediction time differ from observed weather. The evaluation must represent this constraint, along with missing data and changing demand patterns.

What I want to learn

How to make forecast uncertainty useful, and how to carry a carefully evaluated model from an experiment into maintainable software.
